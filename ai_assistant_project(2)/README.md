# AI Assistant (аналог Gemini для Android)

Плавающий ИИ-помощник: пузырь поверх экранов, голосовой ввод, озвучка ответов,
история диалога, чтение экрана, клики, свайпы и ввод текста по команде.

## Возможности
- Чат с Gemini с учётом контекста экрана + история диалога (сохраняется)
- 🎤 Голосовой ввод (SpeechRecognizer) — сказал, и он отправил
- 🔊 Озвучка последнего ответа (TextToSpeech)
- Действия по команде: [CLICK: текст] нажать элемент, [SWIPE: up/down/left/right] свайп, [TYPE: текст] ввести текст
- Перетаскиваемый пузырь поверх всех приложений

## Установка БЕЗ Android Studio (через GitHub — всё в браузере)
1. Создай бесплатный аккаунт на github.com
2. Создай новый репозиторий «ai-assistant» (можно приватный)
3. Загрузи сюда все файлы проекта (Add file → Upload files) — включая скрытую папку .github
4. Открой вкладку **Actions** → запустится сборка автоматически (или «Run workflow»)
5. Через ~3 минуты: Actions → последний запуск → Artifacts → скачай **ai-assistant-apk**
6. Перекинь APK на телефон, открой — разреши установку из неизвестных источников

## Установка через Android Studio (как раньше)
Открой папку проекта → подключи телефон → Run ▶.

## Настройка после установки
1. Ключ Gemini (бесплатно): https://aistudio.google.com/apikey
2. В приложении: сохрани ключ → разреши микрофон → разреши «окна поверх» → включи Accessibility → «Запустить»
3. Примеры команд: «что у меня на экране?», «листни вниз», «нажми кнопку ОК», «напиши Привет в поле ввода»

## Ограничения
- Независимый аналог, не копия приложения Google.
- Распознавание речи использует сервисы Google на устройстве (нужен Android с GApps).
